> 확인일: 2026-10-30
> 목적: 공식 데이터의 출처와 MVP에서 사용할 수 있는 범위를 확인
> 상태: 공식 포털은 확인했으나 API endpoint·이용 조건·공식 앱 URL은 미확정

## 결정

- 공개 포털의 존재만으로 API endpoint, 데이터 최신성, 이용 권한이나 경로별 안전성을 추정하지 않는다.
- 사용자 위치와 경로를 외부에 보내는 실제 경로 제공자는 아직 선정되지 않았다. 경로 API는 모의 테스트에만 사용하고 사용자용 실제 경로 결과를 제공하지 않는다.
- 실제 데이터 연결 재개 조건: 공식 상세 문서·이용 조건 확인, API 접근 방식 확인, 데이터 기준시각·좌표계 검증, 개인정보 전송 범위 검토.
- 데이터 연결이 검증될 때까지 모의 데이터는 테스트 전용이며 실사용 UI의 안전 근거로 노출하지 않는다.

## 출처 접근 한계

2026-10-30 기준 공공데이터포털 검색 결과와 공식 포털은 확인했으나, 데이터 상세 페이지와 API 이용 신청 정보가 이 검토 과정에서 확인되지 않았다. 서울시 공식 안심서비스의 구체 URL·딥링크도 검증되지 않았다. 이 항목은 구현 단계의 선행 조건으로 남긴다.
